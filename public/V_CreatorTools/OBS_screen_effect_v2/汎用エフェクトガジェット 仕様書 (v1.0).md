# OBS Screen Effect V2 現行仕様書

この文書はV2の公開前実装を基準とする。Plugin向けの詳細契約は`effects/template_effect/OBSスクリーンエフェクト開発ガイド (v1.0).md`を参照する。

## 1. システム概要

本システムは、配信画面（OBSブラウザソース）に演出を表示するオーバーレイシステムである。設定、操作、表示を分離し、現行のEffect Transportには名前空間付き`BroadcastChannel API`を使用する。GP Multi Counter V2連携はStandard／SyncではBroadcastChannel、ServerではHTTP／WebSocketを使用する。

---

## 2. コンポーネント構成

### A. 表示部 (Main Display / Screen)

* **役割**: 送信されたデータに基づき、エフェクトを動的にロード・実行する。
* **主要機能**:
    * `BroadcastChannel` の常時監視。
    * エフェクト用JS/CSSの動的インポート。
    * 共通基本パラメータ（色・フォント等）のCSS変数展開。
    * 演出終了後のDOM/メモリのクリーンアップ。

### B. 操作パネル (Controller)

* **役割**: OBSのドック等に配置され、演出のトリガーを送出する。
* **主要機能**:
    * `settings.js` または `LocalStorage` に基づくボタンの自動生成。
    * ボタン押下時、設定されたパラメータをJSON形式で送出。

### C. 設定UI (Configurator)

* **役割**: 全ての設定を管理する母艦。
* **主要機能**:
    * **基本設定タブ**: 解像度、マスター音量、保存管理。
    * **パネル編集タブ**: グリッド数選択、ボタンへのエフェクト割り当て。
    * **詳細設定タブ**: エフェクト固有パラメータ（クラス内の `static manifest` 準拠）の編集。
    * **入出力**: `settings.js` の書き出し、JSON文字列のコピペ用出力。

### D. OBS内部ドック用設定入口

`config_obs.html`はLite版を別実装せず、統合済みの`config.html?view=dock`へ遷移する。ブラウザーとOBSで同じ設定検証・保存処理を使用する。

---

## 3. 設定データの保存・同期

設定の読込優先順位は`LocalStorage > settings.js > settings_default.js`である。設定UIは同一セッション内でFile System Access APIの保存先Handleを保持でき、初回選択後は同じ`settings.js`へ上書きできる。非対応環境ではダウンロードへフォールバックする。JSONのコピー／適用とファイル読込も使用できる。保存時はschemaVersion 1として検証し、`settings.updated` Envelopeで同一Effect Transport上の画面へ通知する。

## 5. データプロトコル

### 5.1 共通基本パラメータ (Base Parameters)

ボタン設定の`params`に保持される共通パラメータ。Effect固有値は保存上`params.options`に置き、RuntimeがPluginへ渡す直前に直下へ平坦化する。

* `duration`: 演出時間 (ms)
* `mainText`: 表示文字列
* `mainColor`: 文字色
* `fontFamily`: フォント種類
* `fontSize`: 文字サイズ
* `volume`: 音量 (0.0 - 1.0)
* `bgOpacity`: 背景暗転の不透明度

### 5.2 送信データ形式 (Payload)

`BroadcastChannel` を流れるデータの例。

```json
{
  "protocol": "vct.obs-screen-effect",
  "protocolVersion": 1,
  "messageId": "UUIDなどの一意なID",
  "source": { "role": "controller", "instanceId": "送信元ID" },
  "type": "effect.trigger",
  "sentAt": 0,
  "payload": {
    "effectId": "crown_effect",
    "params": {
      "mainText": "LEGENDARY!",
      "mainColor": "#ffd700",
      "fontFamily": "Arial",
      "fontSize": "150px",
      "duration": 3000,
      "options": { "particleCount": 150 }
    }
  }
}
```

Effect channelは`vct:obs-screen-effect:v2:channel`、LocalStorageキーは`vct:obs-screen-effect:v2:settings`。許可メッセージは`effect.trigger`と`settings.updated`で、重複message IDは実行しない。

## 6. エフェクト拡張ルール (Manifest仕様)

新しくエフェクトを追加する際は、`main.js` 内のクラスに `static manifest` を定義する。設定UIはこの中身を見て、編集フォームを動的に生成する。

```javascript
class MyEffect {
  static manifest = {
    apiVersion: 2,
    name: "豪華な王冠",
    fields: [
      { name: "particleCount", label: "発生数", type: "number", default: 100 },
      { name: "sparkle", label: "キラキラ", type: "boolean", default: true }
    ]
  };
}
```

---

## 7. 設定の優先順位 (Fallback)

1. **LocalStorage**: 同一ブラウザーコンテキスト上の最新変更。
2. **settings.js**: 保存済みの設定ファイル。
3. **settings_default.js**: 製品初期値。
