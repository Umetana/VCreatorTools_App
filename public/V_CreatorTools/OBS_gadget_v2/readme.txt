OBS Stream Overlay Gadget (Clock & Ticker) v2.0

スタイリッシュな時計、配信時間、そして告知テロップを表示する
OBS用オーバーレイガジェットです。
「GP MULTI COUNTER」とのリアルタイム同期機能も搭載しています。


────────────────────────
📦 同梱ファイル
────────────────────────

index.html
  本体ファイル（OBSに読み込むファイル）

settings.js
  設定ファイル（表示内容や動作を指定するファイル）


────────────────────────
🚀 導入方法
────────────────────────

1. 全てのファイルを同じフォルダに保存します。
2. OBSのソースパネルで「ブラウザ」を追加します。
3. 「ローカルファイル」にチェックを入れ、
   index.html を選択します。
4. 幅を 500、高さを 250 程度に設定してください。
   （内容に合わせて自由に調整できます）


────────────────────────
⚙️ カスタマイズ方法
────────────────────────

本ガジェットの設定は settings.js で行います。

settings.js をメモ帳などのテキストエディタで開き、
内容を書き換えて保存することで動作を変更できます。

※ JavaScriptの知識は必須ではありません。
※ 数値や文字列を書き換えるだけで利用できます。


【主な設定内容】

・基本設定
  SNS情報（X / YouTube 名など）

・告知テロップ
  表示するメッセージ、ラベルの色、個別表示オン・オフ、表示順

・表示モードの切り替え（displayMode）
  時計の横に表示する内容を以下から選択できます。

  "uptime" : 配信開始（読み込み）からの経過時間を表示
  "custom" : 任意の固定テキストを表示
             （目標金額・一言メッセージなど）
  "sync"   : 外部カウンター連携モード
  "none"   : 時計のみを表示


────────────────────────
🧩 設定UIについて
────────────────────────

settings.js を直接編集する代わりに、
本体画面から設定を変更できる「設定UI」も用意されています。

JavaScriptを編集するのが不安な場合は、
以下の手順で設定を行うことができます。


【設定用UIを使う場合】

1. index.html をブラウザ（Chrome等）で開きます。
2. 画面の項目を入力・選択します。
3. 画面右上の歯車ボタンから設定UIを開きます。
4. 設定を変更するとブラウザに保存されます。
5. 設定UI上部の「表示へ反映」ボタンで表示へ反映します。

ローカルサーバーで利用する場合は、URLに以下のパラメーターを付けると
設定UIを開いた状態で起動できます。

  index.html?mode=settings

OBSでは以下のように分けて登録すると便利です。

・ブラウザソース
  index.html

・ブラウザドック
  index.html?mode=settings

設定UIで変更した内容は随時ブラウザに保存されます。
表示へ反映したい場合は、設定UI上部の「表示へ反映」ボタンを押してください。
同じローカルサーバー上で開いているブラウザソースへ再読み込み指示を送ります。

告知テロップは全体の表示オン・オフに加えて、各テロップごとに表示オン・オフを切り替えられます。
一時的に外したい告知は削除せず、個別にオフにしてください。
表示順は各テロップの「上」「下」ボタンで変更できます。


※ パラメーター無しの場合は通常通り表示されます。
※ URLパラメーターで設定値を直接指定する機能はありません。
※ 自動再読み込み指示は BroadcastChannel API を利用します。


【どちらを使ってもOK】

・settings.js を直接編集しても問題ありません。
・設定UIは補助ツールとして自由に利用してください。


────────────────────────
🔗 GP MULTI COUNTER との連携
────────────────────────

GP MULTI COUNTER と連携することで、
カウンターの値をこのガジェットに表示できます。

1. settings.js の displayMode を "sync" に設定します。
2. syncCounterId に連携したいカウンターID
   （例：counter1）を入力します。
3. カウンターを操作すると、
   数値や文字サイズがリアルタイムに同期されます。


────────────────────────
⚠️ 注意事項
────────────────────────

・本ガジェットはローカル環境で動作します。
  APIキー等の取得は不要です。

・settings.js を編集後は、
  OBS側の表示が自動更新されない場合があります。
  その際はブラウザソースを再読み込みしてください。

・商用・非商用を問わず利用可能です。

【メタ情報の自動切り替え】
わんコメのカスタムテンプレとして読み込んだ場合は OneSDK からメタ情報を受信します。
VCT Unified Server から開いた場合は Ms.Bridge が中継する WebSocket /events から受信します。
通常は settings.js の bridgeEventsUrl = "auto" のままで利用できます。
サーバーが別ポートの場合だけ、例: "ws://127.0.0.1:3000/events" を指定してください。
【GP MULTI COUNTER V2連携】
この版はV2 Protocol専用です。V1の obs_counter_sync / type:update は使用しません。
通常のローカルサーバーURLではSyncモード、URLへ ?vctMode=server を付けるとServerモードになります。
対象Counterは settings.js または設定画面の syncCounterId で指定します。
V1対応版は OBS_gadget_v2_old フォルダーに保存されています。
