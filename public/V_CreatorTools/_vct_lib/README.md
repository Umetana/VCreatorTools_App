# VCT Shared Libraries

`_vct_lib` は、V_CreatorTools配下の複数ガジェットで共有するブラウザ向け部品です。

## 方針

- OBSブラウザソース、OBS対話、OBSドック、通常ブラウザで利用可能
- `file://` とローカルHTTPサーバーの両方に対応
- 外部通信・外部パッケージへ依存しない
- 特定ガジェットの保存形式や同期チャンネルへ依存しない
- バージョンディレクトリ単位で互換性を管理する

各ガジェットはHTMLから相対パスで必要なCSS・JSを読み込みます。単体配布時は対象ライブラリのバージョンフォルダーをガジェット内へコピーし、読み込みパスだけ変更できます。

## 提供部品

- `ui/inline-color-picker/v1`: OBS対話画面内で完結するインラインカラーピッカー
- `ui/choice-dialog/v1`: selectをページ内ラジオモーダルで操作する選択UI
