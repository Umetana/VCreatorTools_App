# VCT Clock V2

OBS Studio向けのStandaloneカスタマイズ時計です。ローカルファイルとしてそのまま動作します。

## 主な機能

- 4つの公式プリセット
- 名前を付けて保存できる3つのマイプリセットスロット
- 秒・日付・12/24時間表記・コロン点滅の切替
- 文字、光彩、背景、角丸、文字間隔、黒縁の調整
- LocalStorageによる設定復元と旧V1設定の自動移行
- Tailwind CDN不使用。標準状態はネットワーク接続不要

## OBSへの追加

1. OBSのソースから「ブラウザ」を追加します。
2. 「ローカルファイル」を有効にし、このフォルダの`index.html`を選択します。
3. 幅を`1920`、高さを`1080`にします。
4. 「相互作用」で設定画面を開き、デザインを調整します。
5. 「設定を完全に保存」を押します。
6. OBSプレビューでAltキーを押しながらクロップし、左上の340×120の時計領域だけを残します。

## フォントと通信

「標準（オフライン）」はOS搭載フォントを使用し、通信しません。名前に「オンライン」と表示されたGoogle Fontsは、選択した書体だけをその時点で読み込みます。取得できない場合は自動的に標準フォントへ戻ります。

## プリセット

1. サイバー・ネオン
2. ミニマル・モダン
3. レトロ・ポップ
4. シック・和モダン

プリセット適用後も各項目を自由に調整できます。設定は保存ボタンを押した時点で最終設定として保存されます。

## 旧設定の移行

旧版の`obs_clock_config`と`obs_clock_slot_1`～`3`が存在する場合、V2データがまだないときに自動で読み込みます。正常な項目をV2形式へ移行し、旧データは削除しません。
